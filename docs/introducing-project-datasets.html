6.2 Overview: Use of data sets

This is the general approach we will take to use the datasets for the project assignment.

Step 1: Select one of the four data sets

Each data set focuses on a different type of data. You will be selecting variables from one dataset for your term project. Take a look at the code book and decide which data set you want to use.

Step 2: Select your variables

Look at the codebook to find your variables.

Step 3: Trim down the data set

Before examining the variables, it is helpful to trim down your data set to the variables you have selected.

Additional step:

  • For the following data sets, you have to select a subset of the data
    • VDem: Select one year between 2000 and 2023 (GDP per capita only goes to 2019)
    • World Values Survey: Select one country
    • Asian Barometer: Select one country

Step 4: Examine the univariate distribution and bivariate relationship

6.3 Canadian Election Study 2025

Look at the codebook, which can be found in the same folder as the dataset.

Step 2: Select your variables

Select the variables you want and assign them to the object my_vars.

my_vars <- c("cps25_news_cons","cps25_govt_confusing") #news consumption and internal political efficacy

Step 3: Trim down your data set

The CES is one survey of Canadians in one year, so we don’t need to select a year or a country.

ces_select <- read_dta("Project/CES2025/2025 Canadian Election Study v1.dta") |> # read_dta() reads Stata (.dta) files
  select(all_of(my_vars)) # keep only the variables named in my_vars

Step 4: Examine the univariate distribution and bivariate relationship

Look at the summary statistics

Note that the ordinal variables are measured as numerical variables.

summary(ces_select) # the maximum values (7 and 5) are "Don't know" codes, not real answers

Examine the variables

Bar chart for ordinal variables. Remember to change the numerical variable into a factor with factor().

ggplot(ces_select,aes(x=factor(cps25_news_cons))) + # factor() gives each answer its own bar
  geom_bar()

ggplot(ces_select,aes(x=factor(cps25_govt_confusing))) +
  geom_bar()

Replace nominal categories not found on the ordinal scale to NA

What should we do with don’t know or refused?

Use the if_else() function to make a new variable and set to NA.

ces_select <- ces_select |> # save the new variables in the same data frame
  mutate(govt_confusing=if_else(cps25_govt_confusing==5, # don't know or refused
                                NA, #if yes
                                cps25_govt_confusing), #if no
         news_cons=if_else(cps25_news_cons==7, # don't know or refused
                           NA, #if yes
                           cps25_news_cons)) #if no

Bivariate relationship

If both variables are nominal/ordinal, we can use a stacked bar chart.

ces_select |>
  # is.na() is TRUE when a value is missing, so "== FALSE" keeps people who answered.
  # The comma means both conditions must be true. This only affects the plot:
  # ces_select itself does not change, because we don't save the result with <-
  filter(is.na(news_cons) == FALSE, is.na(govt_confusing) == FALSE) |>
  ggplot(aes(x=factor(news_cons),fill=factor(govt_confusing))) +
  geom_bar(position="fill") + # "fill" makes every bar the same height, so it shows proportions
  theme_bw()

Remove all from environment

To avoid mixing up objects, clear environment before moving on to the next dataset.

rm(list=ls())

Step 2: Select your variables

Look at the codebook and choose your variables.

my_vars <- c("B_COUNTRY_ALPHA","Q73","Q236") #confidence in parliament, experts versus government

Step 3: Trim down your data set

For the WVS data set, select one country

WVS dataset includes a collection of individual surveys in multiple countries. As such, it creates a nested data structure, where we would expect individual-level factors to be confounded by country-level differences. For simplicity, we explore variations within countries.

wvs_canada <- read_rds("Project/WVS/WVS_Cross-National_Wave_7_rds_v6_0.rds") |>
  select(all_of(my_vars)) |>
  filter(B_COUNTRY_ALPHA=="CAN") # choice of country: Canada

Replace nominal categories not found on the ordinal scale to NA

Check the codebook for each variable. q169 and q175 go from 1 to 4, but q184 goes from 1 to 6. Two kinds of codes become NA in the new variables:

  • -1 = missing (for example, the question was not asked in that country)
  • the codes after the scale: 7 = do not understand the question, 8 = can’t choose, 9 = decline to answer

| means “or”, so q169 < 1 | q169 > 4 is TRUE for -1 and for 7, 8 and 9.

ab_korea <- ab_korea |>
  mutate(democracy_problems = if_else(q169 < 1 | q169 > 4, NA, q169),
         us_good_harm = if_else(q175 < 1 | q175 > 4, NA, q175),
         us_influence = if_else(q184 < 1 | q184 > 6, NA, q184))
